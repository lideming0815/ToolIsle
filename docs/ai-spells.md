# AI 咒语管理器

## 已确认的需求

在 BangsBuddy / ToolIsle 中长期保存、整理和反复使用提示词。咒语库独立于剪切板历史，可从任意应用通过用户自定义的全局快捷键呼出，搜索后复制或插入原应用。功能本身不请求大模型服务，不需要 API Key。

首版基于 `dev` 的 `6d84a53ec946a53d9fca8c50805d5bfb282d03aa` 实现。轻量快捷面板与插入修正基于合并首版后的 `6752624`；新增业务代码集中在 `DynamicIsland/ToolIsleFeatures/AISpells/`，只在应用入口、快捷键定义、设置导航和功能开关处接入。

## 使用

### 快速取用

1. 先点进目标应用的输入框，再按 **⌃⌥P**（Control–Option–P）呼出紧凑咒语面板。菜单栏的 **AI 咒语…** 和 **设置 → AI 咒语 → 打开咒语面板** 也能打开面板。
2. 顶部搜索匹配标题、完整正文和分类；横向的 **全部 / 收藏 / 分类** 用于筛选。列表显示标题与多行正文摘要，收藏优先，其余按更新时间排序。
3. **单击整条咒语即可插入**。也可以在搜索框中用 ↑ / ↓ 选中，按回车插入。面板底部显示本次记录的目标应用；没有明确目标时会给出提示。
4. **⌘↩ 仅复制**正文并收起面板，之后自行粘贴。Esc 收起面板。中文输入法正在组词时，回车优先完成组词，不触发咒语操作。

全局快捷键打开的是轻量取用面板。可在 **AI 咒语** 或 **快捷键** 设置中重新录制、清除快捷键；沿用应用已有的快捷键持久化与冲突提示。关闭全局快捷键后，菜单及设置入口仍可使用。

### 整理与管理

点击快捷面板右上角的 **管理**，或选择 **设置 → AI 咒语 → 管理咒语…**，打开完整管理窗口。这里继续提供新增、编辑、删除、分类、收藏、完整正文预览和备份；每条咒语的正文保留原有换行、缩进和中英文内容。首次创建新库时提供用户给出的四条可编辑示例。

管理窗口可组合分类和“仅收藏”筛选，并保留原有显式复制、插入按钮。两个窗口的操作有所区分：

| 操作 | 快捷面板 | 完整管理窗口 |
| --- | --- | --- |
| 单击条目 | 直接插入正文 | 选中并预览全文 |
| ↑ / ↓ | 在搜索框中选择咒语 | 在搜索框或列表中选择咒语 |
| ↩ | 插入选中的咒语 | 复制选中的咒语 |
| ⌘↩ | 仅复制选中的咒语 | 插入选中的咒语 |
| 编辑、分类、收藏、备份 | 通过“管理”进入 | 在管理窗口操作 |

### 插入目标与权限

快捷面板使用不主动激活整个应用的原生浮窗，记录呼出前的外部应用。插入先把完整正文放入系统剪切板，再尝试返回该应用并请求一次粘贴；不会发送回车或自动提交消息。复制和插入都等待触发按键释放后才恢复目标，避免长按回车的重复事件进入聊天输入框。

从目标输入框使用全局快捷键呼出，才能可靠记录本次插入目标。从本应用的设置窗口打开时，如果没有明确的外部目标，则只复制并提示手动粘贴。等待期间若目标退出、用户切换到其他应用或剪切板被更新，不继续向不确定的目标粘贴。复制和插入都使用系统剪切板，已开启的剪切板管理器可以按原规则记录这次复制。

自动插入需要 macOS 辅助功能权限。**设置 → AI 咒语** 显示当前运行进程的实际权限状态，并提供重新检查、打开系统辅助功能设置、复制诊断信息的操作。诊断针对当前正在运行的应用，便于确认安装位置和系统设置中的授权条目是否对应；不包含咒语正文。修改授权或替换安装包后，应返回应用重新检查，不能仅凭系统设置中某个同名条目的开关判断已授权。

缺少权限时仍可复制；快捷面板给出提示和设置入口。运行时权限通过不代表目标应用一定接受粘贴，系统保护、目标输入框状态等仍需实体 Mac 验证。程序请求粘贴，不读取目标输入框来宣称内容已经写入成功。

## 保存和备份

- 数据文件：`~/Library/Application Support/ToolIsle/AISpells/library.json`。
- 独立、带版本的 JSON 文件，写入采用原子替换；只有保存成功后才更新内存中的内容。
- 关闭剪切板、清空剪切板或调整历史条数均不影响咒语库。关闭 AI 咒语功能也不删除已保存数据。
- 删除最后一条咒语后保持空库，重启不会重新插入示例。
- 管理器可导出 JSON 备份，并从本功能导出的 JSON 导入。导入采用合并：已有相同 ID 的本地条目保留，新 ID 追加；重复导入不会重复创建条目。
- 文件损坏、无法读取或版本过新时展示错误并禁止覆盖；保留原文件，修复后可重试读取。非法导入在修改库之前完整校验。

本版不包含云同步、多人共享、变量替换或自动调用 AI。这些能力不影响当前的保存与快速取用流程。

## 验证

核心回归直接运行生产代码，使用独立临时目录，不接触用户的真实咒语或剪切板数据：

```sh
bash scripts/test_ai_spells.sh
```

macOS 上同时编译并测试实际 `AISpellStore`；Linux 运行 Foundation 核心的持久化、搜索和导入回归。

插入流程回归通过注入的运行环境检查真实协调逻辑：目标状态、按键释放、权限拒绝、目标退出、剪切板变更和单次粘贴请求等。这组测试不修改系统权限，也不向外部应用发送内容；真实目标捕获与系统事件投递由 macOS 适配层完成，仍需实机验收：

```sh
bash scripts/test_ai_spell_insertion.sh
```

在带图形会话的 macOS 上，另有原生视图交互回归：

```sh
bash scripts/test_ai_spell_interaction.sh /tmp/ai-spells-interaction
```

该脚本编译生产 `AISpellQuickView` 与 AppKit 搜索框，使用隔离的样例库验证行按钮、搜索、回车插入、⌘↩ 复制、忙碌状态和管理入口，并可生成 `ai-spells-quick-panel.png` 原生视图截图。鼠标按下、抬起和键盘事件进入测试进程的 AppKit 队列，实际触发生产按钮和搜索框；点击位置以固定的 440×500 样例面板原生截图为准，不直接调用待测按钮回调。输入法保护通过真实 `NSTextView` 的 marked text 和生产委托检查，不能替代系统中文输入法端到端验收；其插入回调只记录调用，不等同于外部应用粘贴成功。

完整发行包继续使用仓库既有流程：

```sh
bash publish/publish.sh
```

`.github/workflows/ai-spells-validation.yml` 在 macOS 执行上述三组回归并调用打包脚本，保留 DMG、构建日志和源提交记录。原生 PNG 单独保存在 **AI-Spells-Quick-View** artifact，不混入 **BangsBuddy-AI-Spells-arm64** 安装包 artifact；如果后续回归失败，已生成的截图仍会上传。PR 构建检出该 PR 的实际源提交，便于将 `package.json.source_commit` 与分支代码对应。完整包沿用现有 BangsBuddy 身份与 Thaw 集成，不改签名、辅助组件或更新机制。

### 实机验收

- 全局快捷键在浏览器、编辑器和全屏应用中均能打开面板；修改后旧快捷键失效，新设置重启后保留；冲突由录制器提示。
- 快捷面板为紧凑搜索列表，顶部可进入管理窗口。单击任意条目或搜索后按回车，只插入一次完整正文；⌘↩ 仅复制，管理窗口仍可编辑、预览及备份。
- 设置中可独立禁用咒语功能和全局快捷键；关闭剪切板不影响咒语管理器。
- 四条示例、新建长提示词、多行中英文文本都可完整预览、保存、复制；重启后内容不变。
- 搜索框中文组词、方向键、回车和 ⌘↩ 不误触复制或插入；编辑器回车可以正常换行，取消编辑不改原内容。
- 面板底部目标应用与呼出前实际应用一致；复制/插入后焦点回到该应用。插入不自动发送消息。不具备辅助功能权限、目标应用退出或焦点未恢复时保留已复制文本并提供明确提示。
- 在当前安装包上验证运行时权限状态、重新检查、打开设置和复制诊断；授权之后重新呼出，确认实际输入框收到内容。诊断不包含任何咒语正文。
- 长按回车、⌘↩ 中先松开 Cmd 而继续按住回车，都要等按键完全释放后才返回原应用；持续长按超时则保留面板。等待期间切走应用或开始编辑时取消该次操作，不抢回焦点或丢失草稿。
- 打开在第二块屏幕或全屏 Space 时窗口可见；与系统明暗主题、应用截图可见性设置一致；锁屏不展示咒语面板。
- JSON 导出后导入可恢复新条目；重复导入不覆盖本地修改；损坏或未知版本不会清空旧库。

编译及自动测试不能替代上述焦点、输入法和权限的实体 Mac 验收。

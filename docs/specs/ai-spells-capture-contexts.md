# AI 咒语：剪切板收藏与背景预设组合

批准日期：2026-10-23。仓库 Issues 功能关闭，需求与验收随本 PR 保存。

## 目标

用户已确认同时实现两个方向：
1. 剪切板中的文本一键收藏为 AI 咒语。
2. 项目背景卡与预设咒语组合。

保持既有“快捷呼出 → 点一条 → 插入原输入框”的日常路径；不自动发送聊天内容。

## 功能范围

### 剪切板收藏
- 在现有剪切板展示中提供“存为咒语”，快捷咒语面板和管理窗口也能收藏当前剪切板。
- 仅接收明确的文本、URL、富文本纯文字；不把图片/文件描述或路径误当咒语。
- 打开预填编辑器，保留正文原有空白和换行；标题自动建议，用户保存后才持久化。
- 相同正文提示并定位已有条目；取消不写入；原剪切板及历史条目不被修改。
- 已有未保存编辑时保留草稿，新的收藏请求等待处理。

### 背景卡与组合
- 现有咒语继续使用；新增背景卡和组合类型，可按类型筛选。
- 管理时从背景卡和普通咒语选择片段、排序、移除，预览完整正文并保存为一个组合。
- 组合保留各片段快照；源条目编辑或删除不会暗改已保存组合。用户可主动刷新可用的源片段后再保存。
- 普通咒语、背景卡、组合均使用现有的一次复制/粘贴流程；组合不嵌套。
- 不包括模板变量、自动云同步、最近使用统计或通用插件框架。

## 数据兼容
- 沿用 Application Support/ToolIsle/AISpells/library.json 和原应用身份/快捷键设置。
- 能读取原 schema 1；不在启动时重写文件。首次升级写入前保留原始文件的迁移备份，再原子写 schema 2。
- JSON 导入导出保留类型、顺序和快照；已有同 ID 本地内容不被旧备份覆盖。
- 损坏或不兼容文件保持只读，不替换为示例数据。

## 验收
- 文本/中文/多行从剪切板进入编辑器，确认前无新记录，取消不修改原数据。
- 重复收藏定位原条目，收藏按钮不触发原行复制或粘贴。
- 背景卡 + 咒语按所选顺序生成一个可直接插入的组合。
- 源条目变更/删除后组合保持原文；主动刷新并保存后才更新。
- 旧库读取、迁移备份、重开、组合导入导出和写失败回归通过。
- 既有插入协调逻辑与原生快捷面板回归通过；完整 macOS 应用/Thaw/DMG 构建通过。
- 提交可审查的 PR；发布自用测试 DMG 的 GitHub 直链。CI 不能替代用户 Mac 上的外部输入框实机验收。
